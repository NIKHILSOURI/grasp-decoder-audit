# Results snapshot

A frozen copy of the results reported in the paper, so they can be inspected without re-running anything.
Everything here is regenerated by the commands in the main README (into `results/`, which is not tracked).
Participant = unit of inference; trial ID = participant*10000 + series*100 + lift.

| Folder / file | Contents |
|---|---|
| `RESULTS.md` | Digest of all main numbers (Tables I-III and every experiment) |
| `tables/` | LaTeX (booktabs) tables and the inflation statistics |
| `experiments/e1_*` ... `e7_*` | Per-participant (and per-fold) results of E1 split schemes, E2 leaky selection, E3 chance levels, E4 onset detection, E5 artifact channels, E6 blocked CV, E7 template + EEG |
| `experiments/results_by_subject.csv` | Every fold x participant x target x model: R2, r, template R2, residual gain, trial/window counts, seed |
| `experiments/onset_events.csv` | Every onset test trial: cue and hand-start times, first detection, strict/loose hit, false alarms, rest time |
| `experiments/splits.json` | Train/validation/test participants, series and trials for every fold, with the leakage assertions |
| `experiments/stats_families.csv` | Every hypothesis test: family, size, raw and Holm-adjusted p |
| `verification/` | Round-1/2 audit checks (Holm family, blocked-CV overlap, series folds, filtering, purging, CAR) |
| `round3/` | Round-3 audit (`ANSWERS.md`): number check, embargo, filtering, onset controls, R2 robustness, common grid |
